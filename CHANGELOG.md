# Changelog

## 0.2.0

- Rebuilt the grammar around nested, newline-aware Vim9 statement blocks.
- Added imports, exports, type aliases, classes, interfaces, enums, `while`, and `try` constructs.
- Expanded expressions, literals, assignments, typed parameters, method pipelines, indexing, and slicing.
- Added corpus coverage and editor queries for highlights, locals, tags, and folds.
- Unified the generated C symbol and all language bindings on `tree_sitter_vim9`.
- Added reproducible generation, cross-platform CI, binding smoke tests, and full project documentation.

## 0.1.0

- Initial Vim9 subset parser.
